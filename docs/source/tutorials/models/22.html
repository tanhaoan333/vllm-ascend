阅读约定

模型算子图 ≠ kernel 时间线。一个逻辑框不一定对应一个 kernel；NPU 可以融合多个框。虚线表示条件、缓存或实现映射，不代表新增网络层。

模型权重基准：tha/hy3_a3b_codec。Stage 0 以 hf_model/ 为模型目录（含 Talker、Whisper fbank encoder、speaker_adaptor、audio_encoder/config.json）；loader 按 <model>/../decoder 加载 Stage 1 的 decoder/。图中所有尺寸均已用这些目录的 config 与 safetensors header（只读、未加载张量）交叉核对；部署参数来自 vllm_omni/deploy/uniditar_tts_codec.yaml。hf_llm_model/ 是另行导出的纯 LLM 产物（排除 fbank_encoder / speaker_adaptor / audio_codec_tokenizer），不在本 TTS 两阶段图的加载路径上。

组件（权重目录）参数量存储已核对的关键形状
Talker HYV3（hf_model: model.* + lm_head）30.15B 总量；每 token 激活约 2.96B（不含 embedding 与 head），含二者约 3.54BBF16 56.2 GiBq/k/v/o：[4096,2048]/[512,2048]/[512,2048]/[2048,4096] ×48；layer0 dense 6912；47 层 × 128 experts [768,2048]；shared_mlp 768 ×47；expert_bias F32[128]；embed / lm_head [141568,2048]
Whisper fbank encoder + adaptor（hf_model: fbank_encoder.*）1.63BBF16 3.03 GiBconv1 [2048,128,3]、conv2 [2048,2048,3]；32 层 q/k/v/out [2048,2048]（k 无 bias）、fc1 [8192,2048]；adaptor.projection [2048,2048]
speaker_adaptor（hf_model）4.2MBF16[2048,2048] + bias
ICL audio_tokenizer（decoder/audio_tokenizer）权重文件 3.72B，实际只用 0.47BF32权重文件含 32 层 encoder + ASR decoder；loader 只取前 9 层 + conv + feat_norm + ssl_proj [128,2048,1] + codebook [1,8192,128]
FM token2latent（decoder/fm_model）0.396B（18 层 blocks 0.34B，其中调制投影 0.115B）F32 1.5 GiB，运行时转为部署 dtypetoken_embedding [8193,1024]；acoustic_delay 1 层（带 q/k_norm[64]）；token_proj 2 层（无 q/k_norm）+ shuffle [2048,1024]；input_proj [1024,1152]；conv_embed [1024,64,31]；blocks 带 modulation [6144,1024]；output [64,1024]；start_latent [48,64]；RoPE inv_freq 反推 base≈50000
Speaker Conformer（decoder/speaker_encoder + speaker_embedding_mapping.pt）33M + 0.26MF32Conv2d [512,1,3,3]、[512,512,3,3]；embed.out [512,9728=512×19]；8 层（FFN [1024,512]、depthwise [512,1,15]、pos_bias_u/v [8,64]）；pool_proj [128,512]；pool_norm γ[256]；mapping Linear(256→1024)
VAE / BigVGAN（decoder/wavegan）decoder 0.115B，encoder 0.032B；flow 0.012B（不加载）F32，weight_norm（加载时折叠）conv_pre [1536,64,7]；ups [1536,768,10]…[48,24,4]；18 个 resblocks（6 stage × k3/7/11）；conv_post [1,24,7]；encoder 末层 [128,768,3]（=2×Z）；FIR filter 12 taps

仍由代码决定、权重中不存在的项：RMSNorm/LayerNorm eps、attention mask 语义、采样策略、sample_rate=24000（wavegan config 未写，配置类补足）、use_vae=true、resblock="1"。FM config 中的 use_flash_attention=false、dropout 等训练字段当前构造不消费，不代表推理后端。

符号：B 批大小，T 当前序列长度，S 可见 KV 长度，D 隐藏宽度，Hq/Hkv Query/KV 头数，dh 单头宽度。线性层统一用数学写法 XW+b；存储中的权重可能转置。
